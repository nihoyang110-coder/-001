## 一、开源工具

### 1. EL4CTEO/blender-skills
- **类型**：技能包（MIT，2026-10-14 首次提交，要求 Blender 5.2+）
- **作用**：教 AI 用正确方式操作 Blender。22 个技能：`blender-core` 总入口与 5.x API 规则；硬表面/雕刻/几何节点建模；重拓扑 + UV；PBR 材质自动接线；烘焙法线/AO/曲率/ORM；Rigify 绑定、ARKit 52 表情；动画与根运动；LOD 与面数预算；导出 Roblox/Unity/Unreal/Godot/网页/USD；渲染、灯光、天气、模拟；资产质检（穿插、悬空零件、法线翻转、非流形、重复点、n 边面、权重）。能装进 Claude Code、Codex、Gemini CLI、Copilot、Cursor。
- **评价**：我们在 bpy 5.2.2（无显卡）实跑自带测试：50 项里 46 过、1 败（插件打包要完整 Blender 路径，环境原因）、3 跳过（要显卡）。说明脚本能用；但它管的是“操作规范”，成品好不好看还是看模型本身。项目很新，作者只给了自选对比，没有独立评测。
- **是否值得用**：✅ 推荐。是目前最完整的通用 Blender 技能包，质检脚本可以直接接到我们自建的“尺寸核验器”上。显卡相关的 3 项测试等有显卡电脑后补跑。
- **来源会话**：「新闻追根溯源与判断」 · `session_01H8zdS8RscwM53yYrX4vHfj`
  - 起因是视频号截图「Codex 变身专业 3D 建模师：22 个 Blender Skill」，要求核实并找评价高的开源工具
  - 克隆仓库直读：MIT，22 技能，10-14 才建（[[F-0228]]）
  - 实跑 `BAS_SKIP_GPU=1 python tests/run_all.py`：46/1/3（[[F-0229]]）
  - 结论：技能包真实可用，“变身专业建模师”是夸大（[[F-0230]]）

### 2. Blender Lab MCP（Blender 官方实验室）
- **类型**：连接器（GPL-3.0+，v1.0.0 于 2026-04-27，需 Blender 5.1+）
- **作用**：让 AI 连上正在运行的 Blender：读场景、调试、跑脚本。刻意做小，不做“生成艺术”。
- **评价**：官方维护、范围小，安全面也小；Anthropic 的 Claude Blender 连接器就用它。缺点是功能少（没有素材库、3D 生成），而且本次只看了二手资料，官方仓库没直读。
- **是否值得用**：✅ 推荐作首选连接器。日常建模、质检、渲染用它就够；要素材库时再换 MCP for Blender。
- **来源会话**：「新闻追根溯源与判断」 · `session_01H8zdS8RscwM53yYrX4vHfj`
  - 搜“热门 Blender MCP”时找到，确认 v1.0.0、GPL-3.0+、需 5.1+（[[F-0232]]）
  - Blender 基金会表态：Blender 不计划内置生成式 AI
  - 官方仓库未直读，置信度记为“中”

### 3. MCP for Blender（ahujasid，原 blender-mcp）
- **类型**：连接器（MIT，约 2.9 万星，2026-09 第三方统计）
- **作用**：读场景、执行任意 Python、搜索导入 Poly Haven 材质/HDRI/模型和 Sketchfab 模型、调用 Hyper3D / 混元3D 等生成 3D；一条命令装到 Claude Desktop/Code、Codex、Cursor。
- **评价**：功能最全、社区最大。但 2026 年披露两个漏洞：`execute_blender_code` 不做沙箱（CVE-2026-10688）；Poly Haven 下载路径穿越可写任意文件（CVE-2026-66004，1.6.5 修复）。生成类功能要第三方账号。
- **是否值得用**：🟡 按需。需要素材库或 3D 生成时用；必须 ≥1.6.5、只在本机监听、先存档，最好配我们自建的“安全执行层”。远程显卡电脑上**不要**把它直接暴露到网络。
- **来源会话**：「新闻追根溯源与判断」 · `session_01H8zdS8RscwM53yYrX4vHfj`
  - 克隆仓库直读 tools 定义（[[F-0231]]）
  - 搜热度：约 2.9 万星（Star History，二手）
  - 搜安全：两个 CVE 与审计建议（SentinelOne、Vulert，二手）

### 4. Blender Agent Studio（ifBars）
- **类型**：闭环插件（MIT，需 Bun）
- **作用**：给 Claude Code / Codex 用。一次交付三样：可编辑 `.blend`、生成它的 Python、渲染图。自检安装；参考图多角度比例对比；招牌/标签 2D 设计；可录建模过程延时视频。
- **评价**：流程完整，延时视频对做内容有用。作者自己承认“自动检查能抓坏几何，抓不了审美”。我们只读了仓库，没实跑。
- **是否值得用**：🟡 按需。想要“开箱即用的闭环”时试；我们的转台视频、参考图比对可以借它的做法。
- **来源会话**：「新闻追根溯源与判断」 · `session_01H8zdS8RscwM53yYrX4vHfj`
  - 搜原帖仓库时一起找到，克隆直读
  - README 自述的局限被用作 [[F-0230]]（“抓不了审美”）的依据
  - 未实跑

### 5. dream-loop（achimala）
- **类型**：技能 / 方法（MIT）
- **作用**：先用生图模型画出目标效果图 → AI 按图搭建 → 另一个 AI 评审员对比截图给意见 → 循环直到接近。
- **评价**：思路对，正好补“审美”这块。但作者只在 GPT-6 Astra + Codex 上测过，评审靠 AI 主观判断，需要生图和看图能力。
- **是否值得用**：🟡 借思路。我们的“参考图比对评审器”就是把它的主观评审换成可量化的分数。
- **来源会话**：「新闻追根溯源与判断」 · `session_01H8zdS8RscwM53yYrX4vHfj`
  - 搜原帖仓库时找到，克隆直读
  - 记下测试范围窄的问题
  - 启发了自建工具 #3

- **评价**：建筑行业里最全的一套，但和日常 3D 内容无关。未实跑。

- **来源会话**：「新闻追根溯源与判断」 · `session_01H8zdS8RscwM53yYrX4vHfj`

### 9. Flamenco（Blender 官方渲染农场管理器）

## 二、我们可以自建的工具

现成工具已经覆盖“会操作 Blender”和“通用流程”。空白在：**中文场景、尺寸与可信度、安全、内容发布、远程显卡渲染**。

设计前提：以后会联网一台有显卡的电脑。所以每个工具都分成“在哪跑”：
- **本地/云端（无显卡）**：bpy 后台模式 + Workbench/EEVEE 低质量预览即可
- **显卡机**：Cycles 正式渲染、显卡测试、转台视频成片

| # | 工具 | 解决什么 | 在哪跑 | 难度 | 优先级 |
|---|---|---|---|---|---|
| 1 | 尺寸核验器 | “看着对、尺寸错” | 无显卡 | 低 | ★★★ |
| 7 | 远程渲染节点 | 把重渲染交给显卡机 | 显卡机 | 中 | ★★★ |
| 4 | 转台视频/封面出图器 | 接小红书/视频号发布 | 预览无显卡，成片显卡机 | 低 | ★★★ |
| 2 | 安全执行层 | MCP 执行任意代码的 CVE | 两边都要 | 中 | ★★ |
| 3 | 参考图比对评审器 | 让 dream-loop 的评审变成数字 | 无显卡（剪影）/显卡机（高质） | 中 | ★★ |
| 6 | 同题评测台 | 核查“快 99 倍”这类说法 | 显卡机跑批 | 中 | ★★ |
| 5 | 国内平台导出预设 | 缺微信/抖音小游戏、Cocos、three.js | 无显卡 | 中 | ★ |

建议顺序：**1 → 7 → 4 → 2 → 3 → 6 → 5**。调研笔记原顺序是 1 → 4 → 2 → 3 → 6 → 5；这里把远程渲染节点提到第二，因为 4、3、6 的成片质量和显卡测试都依赖它。

每个自建工具的“来源会话”都是同一次：「新闻追根溯源与判断」 · `session_01H8zdS8RscwM53yYrX4vHfj`，下面只写与该工具相关的要点。

### 自建 1：尺寸核验器
- **作用**：把用户要求（“长 120mm、孔径 8mm”）解析成清单；建完自动量 `dimensions`、孔径、壁厚，输出偏差表，超差就退回重做。
- **怎么做**：bpy 现成接口；复用 EL4CTEO `blender-asset-qa` 的脚本结构；输出 Markdown 偏差表，方便贴进笔记。
- **是否值得做**：✅ 一两天出原型，直接提升可信度。
- **来源会话要点**：
  - 调研结论：AI 建模最常见的问题是“尺寸错”，现成技能包没有专门检查
  - EL4CTEO 的质检脚本实跑可用（[[F-0229]]），可以直接接
  - 原排序第 1

### 自建 7：远程渲染节点（新增）
- **作用**：在云端或本机让 AI 建好模型后，把 `.blend` 发到有显卡的电脑上用 Cycles 渲染，结果图/视频自动传回。
- **怎么做（由轻到重三种）**：
  1. **Claude Code 远程控制**：显卡机上开一个 Claude Code 会话，用远程控制从手机/网页指挥，直接在那台机器上跑 `blender -b scene.blend -E CYCLES -o //out/ -a`。最省事，适合先跑通。
  2. **渲染任务脚本**：显卡机上一个小服务，只收“文件 + 渲染参数”（引擎、分辨率、帧范围、采样），排队执行，完成后回传。通过 Tailscale 之类的私网连，不开公网端口。
  3. **Flamenco**：机器多了再上。
- **安全**：只收 `.blend` 和参数，不收任意代码；渲染前检查 `.blend` 里的自动运行脚本（Blender 默认关闭，保持关闭）；MCP 只监听本机。
- **是否值得做**：✅ 有显卡机后第一件事。顺带补跑 EL4CTEO 被跳过的 3 项显卡测试，把 [[F-0229]] 更新完整。
- **来源会话要点**：
  - 用户提出“未来有可能联网一个有显卡的电脑，控制在上面渲染”
  - 调研局限：没有显卡，3 项渲染测试跳过，也没让 AI 完整建一个模型
  - MCP for Blender 的执行代码漏洞（[[F-0231]]）决定了远程端不能直接暴露 MCP

### 自建 4：转台视频/封面出图器
- **作用**：一键出 360° 转台 MP4（9:16、3:4）+ 封面 PNG + 线框对比图，套我们 J 模板的字体配色。
- **怎么做**：相机绕物体的固定动画 + 渲染预设；无显卡时 EEVEE/Workbench 出预览，显卡机出成片。
- **是否值得做**：✅ 低难度，直接服务小红书/视频号。
- **来源会话要点**：
  - 同一会话在做 FactCheck 内容的多平台发布（小红书/视频号，后加 YouTube）
  - Blender Agent Studio 的延时视频功能可借鉴
  - 原排序第 2

### 自建 2：安全执行层
- **作用**：AI 发给 Blender 的代码先过检查：只放行 bpy/bmesh/mathutils/math；禁止越界读写文件、联网、开子进程；执行前自动存档；全部留日志。
- **怎么做**：Python AST 白名单检查，包在 MCP 的执行入口前。
- **是否值得做**：✅ 用 MCP for Blender 或开远程渲染前必须有。
- **来源会话要点**：
  - 两个 CVE：执行代码无沙箱、Poly Haven 路径穿越（[[F-0231]]）
  - 安全建议：只本机监听、先备份、能用专用工具就不用“执行任意代码”

### 自建 3：参考图比对评审器
- **作用**：多角度渲染剪影，与参考图做轮廓重合度（IoU）和比例对比，给数字分 + 文字意见。
- **怎么做**：Workbench 纯色剪影 + 图像对齐；分数写进评测结果。
- **是否值得做**：🟡 1、7 之后做。
- **来源会话要点**：
  - dream-loop 的评审靠 AI 主观判断，缺可量化标准
  - Blender Agent Studio 有“参考图多角度比例对比”，可参考

### 自建 6：同题评测台
- **作用**：固定 20 道中文建模题，分别在“装/不装技能包”“不同模型”下跑，自动打分（质检通过率、尺寸偏差、轮廓重合度、耗时、费用），结果写进事实清单。
- **怎么做**：组装 1、3；批量任务放显卡机跑。
- **是否值得做**：🟡 能反过来服务事实核查，例如验证“变身专业建模师”。
- **来源会话要点**：
  - [[F-0230]]：作者只给自选对比，没有独立评测
  - 视频号同类标题常夸大（参见 [[F-0221]]）

### 自建 5：国内平台导出预设
- **作用**：微信/抖音小游戏、Cocos Creator、网页 three.js 的面数/贴图/格式预算，导出前自动检查。
- **怎么做**：在 EL4CTEO 导出技能旁加预设，先查各平台规范。
- **是否值得做**：🟡 有真实需求再做。
- **来源会话要点**：
  - EL4CTEO 导出只覆盖 Roblox/Unity/Unreal/Godot/网页/USD，缺国内平台
