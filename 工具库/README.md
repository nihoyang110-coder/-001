# 工具库

按领域整理“值得用的现成工具”和“我们自己要做的工具”。每个条目都写清：作用、评价、是否值得用，以及它来自哪次会话，方便以后回查。

## 目录
| 文件 | 领域 | 更新 |
|---|---|---|
| [Blender-AI建模.md](Blender-AI建模.md) | Blender + AI 建模：连接器、技能包、闭环插件、自建工具、远程显卡渲染 | 2026-10-21 |

## 条目格式
每个工具一节，固定字段：

| 字段 | 写什么 |
|---|---|
| 类型 | 连接器 / 技能包 / 闭环插件 / 方法 / 自建 |
| 作用 | 它能干什么（白话） |
| 评价 | 优点、问题、我们是否实测过 |
| 是否值得用 | ✅ 推荐 / 🟡 按需 / ⛔ 暂不用，加一句理由 |
| 来源会话 | 会话标题、会话编号、3–5 行要点 |

“是否实测”只认我们自己跑过的结果；星数、口碑写明是第三方数据和时间点。
