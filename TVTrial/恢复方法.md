# 恢复方法

从轻到重，依次尝试。前两种都不会丢数据。

## 1. 一键恢复（推荐）

需要 Mac 能连上电视（临时重新打开 USB 调试）。在 cleanyourtv 文件夹里，告诉本地 Claude“运行恢复脚本”，或自己在终端执行：

```bash
# Google TV（原桌面是 launcherx）
TV_HOST=电视IP tools/restore.sh 你的清单.txt com.google.android.apps.tv.launcherx
# Android TV（原桌面是 tvlauncher，默认值）
TV_HOST=电视IP tools/restore.sh 你的清单.txt
```

它会：重新启用清单里所有被停用的应用、把原桌面设回主屏、恢复动画速度。
它**不会**：删掉新桌面（到 设置 → 应用 → `com.gathin.tvhome` 里手动卸载）；也不知道清单之外你手动停用的东西。所以**清单文件一定要保存好**。

## 2. 不用电脑，在电视上手动恢复

设置 → 应用 → 查看全部应用 → 显示系统应用 → 找到被停用的应用 → “启用”。
原桌面名字一般叫“Google TV 主屏幕 / Android TV Home”。

## 3. 紧急情况

| 情况 | 做法 |
|---|---|
| 换桌面后电视每分钟掉线/黑屏（Google TV） | 尽快执行：`tools/venv/bin/python -I tools/tv.py 'pm enable --user 0 com.google.android.apps.tv.launcherx'` |
| 主页键打开了一个奇怪的工厂测试界面 | 说明原桌面被提前停用了，用上面的命令启用原桌面 |
| 开机显示 “Can't load Android system” | **选 “Try again”**，进系统后运行一键恢复。不要先选恢复出厂 |

## 4. 最后手段：恢复出厂设置

只有上面都不行时才用。会清空电视上的账号、已装应用和设置，系统自带应用全部回到出厂状态（因为我们只是“停用”，没有删除任何东西，出厂恢复后它们都会回来）。

- 能进设置时：设置 → 设备偏好设置 → 关于 → 恢复出厂设置。
- 进不了系统时：多数海信安卓电视是拔掉电源 → 按住机身电源键（或遥控器特定键）再插电，进入 Recovery 菜单选 “Wipe data/factory reset”。**具体按键因型号而异，请查你型号的说明书或海信日本客服，不要乱试。**
- 做出厂恢复前，如果是 Google TV 且停用过 `setupwraith`（开机向导），最好先恢复它，否则开机向导可能出问题。
