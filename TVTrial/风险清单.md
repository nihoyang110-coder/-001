# 风险清单（动手前请读完）

| 风险 | 会怎样 | 怎么防 |
|---|---|---|
| **误停用系统组件** | 电视台节目看不了、遥控器失灵、开机进恢复模式（另一台海信停用 smartsense 等三个包后出现过） | 只停用、不卸载；每批 ≤5 个，每批后测试；不确定的包不碰；恢复脚本先写好 |
| **日本电视台功能** | 地上波/BS/CS、B-CAS/ACAS 卡相关组件被停用会无法收看 | 提示词里已列为“绝不停用”；每批后实测看一个电视台 |
| **保修** | 停用不改动系统分区，一般可以通过恢复/出厂恢复回到原样；但打开开发者模式、修改系统可能被厂商认定为非正常使用，**是否影响保修以海信日本的说法为准**；另外日本购入的机器在国内本来就可能不享受保修 | 去修之前先运行恢复脚本，关闭开发者选项 |
| **系统签名限制** | 有的电视（项目里记录的两款国内 TCL）只能去广告不能换桌面；VIDAA 系统完全不能用这个方法 | 先检查能否安装，失败就停，不硬试 |
| **网络调试开着的安全风险** | 同一 Wi-Fi 里的设备都有机会尝试连电视的调试端口；一旦授权，对方能控制电视、装应用 | 只在“允许 USB 调试”弹窗出现且是你自己在操作时才点允许；**做完马上关掉 USB 调试/网络调试和开发者选项**；不要在公共/访客网络上做 |
| **固件更新被停用** | 收不到海信的系统更新（含安全补丁） | 让 Claude 问你时选择“保留更新”，或每隔几个月临时启用一次 |
| **系统更新后部分东西回来** | 广告或原桌面可能复活 | 用保存的清单再跑一次即可 |
| **Google TV 换桌面的已知坑** | 开机向导抢主页、电视反复掉线；遥控器 YouTube 键失效 | 按恢复方法里的紧急命令处理；参照项目 TROUBLESHOOTING |
| **USB 口断电** | 开着调试时插在电视上的 U 盘/音箱可能没电 | 做之前拔掉，做完关掉调试 |
| **花钱的事** | Claude Code 使用会消耗你的 Claude 额度；装 JDK/Android SDK 约占几 GB 磁盘 | 换桌面需要编译时，Claude 会先问你 |
