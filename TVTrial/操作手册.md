# 操作手册（Mac + 海信 Google TV / Android TV）

> **只在“可行性判断.md”里确认是 Google TV / Android TV 之后再做。** VIDAA 电视请直接看那份文件里的替代方案。
> 全程大约 30–60 分钟。每一步都写了“怎么撤销”。

---

## 第 0 步：准备

- 电视和 Mac 连**同一个 Wi-Fi**（同一个路由器，不要一个连 5G 访客网络）。
- 拍几张照片：电视主页、设置里的“关于”页面（型号、Android 版本）。出问题时对照用。
- 拔掉插在电视 USB 口上的 U 盘、音箱（有些机器开着调试时 USB 口会断电）。
- **撤销：** 无需撤销。

## 第 1 步：电视上打开“开发者选项”

1. 设置 → 设备偏好设置（Device Preferences / デバイス設定）→ 关于（About / デバイス情報）。
2. 选中“版本号 / Build / ビルド”，**连续按遥控器 OK 键 7 次**。
3. 屏幕提示“您已处于开发者模式 / You are now a developer”。
- **会弹什么：** 可能要求输入电视的 PIN 码。
- **撤销：** 设置 → 开发者选项 → 顶部总开关关掉。

## 第 2 步：打开 USB 调试 / 网络调试

1. 返回设备偏好设置 → **开发者选项**。
2. 打开 **USB 调试（USB debugging）**；如果还有“网络调试 / ADB 调试 / 无线调试（Wireless debugging）”，也打开。
3. 记下电视的 IP 地址：设置 → 网络 → 当前 Wi-Fi → 一串像 `192.168.1.50` 的数字。
- **会弹什么：** “允许 USB 调试吗？”的警告，选“确定”。
- **撤销：** 关掉这两个开关即可。**全部做完后一定要关**（见风险清单）。

## 第 3 步：Mac 上安装 Claude Code

1. 打开 Mac 的“终端”（启动台 → 其他 → 终端）。
2. 按官方说明安装 Claude Code：https://docs.claude.com/en/docs/claude-code/setup ，装完输入 `claude` 并按提示登录。
3. 在终端里依次输入（把项目下载到“文稿/cleanyourtv”）：
   ```
   cd ~/Documents
   git clone https://github.com/Gathin23/cleanyourtv
   cd cleanyourtv
   claude
   ```
- **会弹什么：** Mac 可能提示“需要安装命令行开发者工具”，点“安装”，等它完成后重新输入命令。
- **撤销：** 删掉“文稿”里的 cleanyourtv 文件夹即可，电视没有任何变化。

## 第 4 步：把提示词交给 Claude

1. 打开本目录的 [给本地Claude的提示词.md](给本地Claude的提示词.md)，把“从这里开始复制”到“复制到这里结束”的内容整段复制。
2. 把里面的 `【型号】`、`【IP】` 换成你的实际信息，粘贴进终端里的 Claude，回车。
- **会弹什么：**
  - Mac 弹“是否允许‘终端’查找本地网络上的设备？”→ 选**允许**。
  - Claude 每次要执行命令时会问你是否允许，看不懂可以直接问它“这一步是干什么的”。
  - **电视上**弹“允许 USB 调试吗？（RSA 密钥指纹…）”→ 勾选“始终允许这台电脑”，选**允许**。如果多次弹出，每个都按返回键关掉，再让 Claude 重试。
- **撤销：** 到这一步电视还没被改动。

## 第 5 步：备份（Claude 自动做，你确认）

Claude 会把电视的软件列表、设置等保存到 Mac 上一个 backup 文件夹，并写好恢复脚本。
- **你要做的：** 确认它告诉你“备份完成”，并记下备份文件夹位置。
- **撤销：** 备份只是读取，不改电视。

## 第 6 步：去广告（停用预装）

1. Claude 会列一张清单：哪些是广告/统计/推荐、哪些是预装应用，并问你哪些在用（例如 Netflix、YouTube、TVer、U-NEXT、语音助手、投屏）。**你在用的都要勾“保留”。**
2. 你确认后，它一小批一小批地停用，每批后截图、检查电视是否正常。
3. **每批之后自己按一下遥控器：** 主页键、音量、切换信号源（地上波/BS/HDMI）、看一下电视台节目。有异常马上告诉 Claude“停，恢复上一批”。
- **撤销：** 让 Claude 运行恢复脚本，或见 [恢复方法.md](恢复方法.md)。

## 第 7 步：换 Apple TV 风格桌面（可选）

1. Claude 先检查电视是否允许安装外部应用；**如果报 `INSTALL_FAILED_VERIFICATION_FAILURE` 或签名错误，就停在这里**，只保留去广告的成果。
2. 它会问你：底部放哪 4 个常用应用、顺序如何。
3. 安装后它会先打开新桌面测试，**确认能用再**设为主屏。
4. 你测试：主页键回到新桌面；“Inputs”按钮能切到地上波/BS/HDMI；应用都能打开。
- **撤销：** 恢复脚本会把原来的桌面设回主屏；新桌面可在 设置 → 应用 里删除。

## 第 8 步：收尾（重要）

1. 让 Claude 把恢复脚本、它停用的清单保存好（建议复制一份到 U 盘或云盘）。
2. **电视上关掉 USB 调试 / 网络调试**，再关掉开发者选项。新桌面不需要它们也能用。
3. 重启电视一次，确认开机正常。
4. 把结果（成功/失败、截图、Claude 的总结）发回给我，我再帮你调整。

## 常见问题

| 现象 | 怎么办 |
|---|---|
| Claude 说 “No route to host” 连不上 | Mac 本地网络权限问题。系统设置 → 隐私与安全性 → 本地网络 → 打开“终端”。项目自带的 Python 工具能绕开这个问题，Claude 会自动改用 |
| 一直连不上，端口 5555 关着 | 用“无线调试”配对：开发者选项 → 无线调试 → 使用配对码配对，把屏幕上的 IP、端口、配对码告诉 Claude |
| 电视反复弹“允许调试吗” | 每个都按返回键关掉，让 Claude 用同一把密钥重连 |
| 截图是黑的 | 正在播电视台/HDMI 时截不到，先按主页键 |
| 换桌面后没有屏幕键盘 | 告诉 Claude，它会用 `ime set` 把输入法设回 Google 键盘 |
| 电视每分钟掉线、反复黑屏 | 告诉 Claude 立刻执行：`pm enable --user 0 com.google.android.apps.tv.launcherx`（Google TV 的原桌面），详见恢复方法 |
| 开机出现 “Can't load Android system” | **选 “Try again（重试）”，千万别选 “Factory data reset”**，进系统后运行恢复脚本 |
