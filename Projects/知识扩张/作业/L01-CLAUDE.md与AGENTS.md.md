# L01：CLAUDE.md 与 AGENTS.md——标准、限制、对照与升级

## 1. 两个文件分别给谁看
| 文件 | 谁会读 | 说明 |
|---|---|---|
| `CLAUDE.md` | Claude Code | Anthropic 的格式 |
| `AGENTS.md` | Codex（OpenAI 的编程智能体，不是网页版 ChatGPT 聊天）、Cursor、Gemini CLI、Devin、Jules、Zed、Warp 等 20 多个工具 | 开放格式，2025-12 起由 Linux 基金会旗下组织管理。Claude Code v2.1.277 起也能读，但**只在没有 CLAUDE.md 时才读** |

## 2. 各来源的格式要求与限制
| 来源 | 级别 | 长度 | 格式与内容 |
|---|---|---|---|
| CS146S 第 4 周作业原文 | 一手（克隆仓库） | 约一页；“每次都会加载，长度就是成本” | 至少五块：项目是什么、结构、命令（可直接复制）、约定、护栏（不能碰的、容易用错的命令）。每行都要针对本仓库；通用建议和 README 复述算凑字数 |
| Claude Code 官方文档《How Claude remembers your project》 | 一手（官方文档全文） | **每个文件 200 行以内**，超过会多占上下文、降低遵守率；用 `@` 导入的文件照样算进上下文成本 | 用标题和要点分组；写成可检验的具体规则（“提交前运行 `npm test`”，不写“记得测试”）；两条矛盾时可能随便挑一条。导入最多嵌套 4 层；块级 HTML 注释不会进上下文；根目录 CLAUDE.md 在上下文压缩后会重新读入；它以用户消息的身份送达，不是硬性约束，必须遵守的规则改用 hook |
| Claude Code 官方《Best practices》 | 一手（官方文档全文） | 用 `/init` 生成初稿后“主要工作是删” | 只写 Claude 自己看代码看不出来的：验证命令、代码里容易误导的地方、不在仓库里的决定、纠正过两次的事。**不再建议描述架构和目录**（Claude 会自己读）；不再建议用 IMPORTANT、全大写来强调；可用 `/doctor prompt-audit` 查过时和矛盾的条目 |
| agents.md 官网 | 一手（克隆官网仓库，2026-09-10） | 无硬性规定 | 普通 Markdown，没有必填字段。推荐：项目概述、构建与测试命令、代码风格、测试说明、安全注意。冲突时离被改文件最近的那份优先，用户在对话里说的话优先于文件 |
| Codex 源代码 | 一手（克隆 openai/codex，2026-10-28） | **所有 AGENTS.md 合计 32 KiB**（`project_doc_max_bytes`），超出部分不加载 | 从项目根目录到当前目录逐层拼接；每层先找 `AGENTS.override.md`，没有再找 `AGENTS.md`；不受信任的项目不加载 |
| HumanLayer《Writing a good CLAUDE.md》（课程指定阅读） | 二手（原文打不开，只有摘要） | 建议 300 行以内，作者自己的不到 60 行；前沿模型能稳定遵守约 150–200 条指令 | 别把它当代码检查工具（风格交给 linter）；采用渐进披露：主文件只做指引，细节放到其他文档按需读取 |
| OpenAI《Harness engineering》 | 二手 | 约 100 行 | AGENTS.md 当“目录”，指向 docs/ 里的详细文档 |

**来源之间的冲突**：CS146S 要求写“结构”，Anthropic 最新文档说不必描述目录。处理办法：只写**看代码看不出来**的结构，比如哪些区块是脚本生成的、暂存区怎么用、编号怎么取。

## 3. 我们的现状（修改前）
- 仓库里**没有** CLAUDE.md，也没有 AGENTS.md
- 规则散在各处：
  - 技能 SKILL.md（8.6 KB，只在技能被触发时才读）
  - FactCheck/README.md、变更记录
  - 两条定时任务的提示词，各自重复写了一遍规则
  - 会话快满时自动生成的长摘要，会话结束就没了
- 后果：
  - 每开一个新会话，都要重新摸索命令和规则
  - 10-26 首次定时回看时，新会话不知道推送受限这类背景
  - 规则改了，要改好几处

## 4. 升级方案（已执行）
- **AGENTS.md 作为唯一的规则来源**（36 行，3.2 KB，约为 Codex 上限的 1/10）：命令、事实库约定、生成文件不要手改、护栏
- **CLAUDE.md 第一行 `@AGENTS.md`**，下面只放 Claude 专用的内容（技能、常驻会话、页面地址、并行核查），合计 43 行
- 这样 Claude Code 和其他工具读到的是同一份规则，以后只改 AGENTS.md
- 写之前把文件里的每条命令都实际跑了一遍；跑的过程中发现并修复了 `factdb due` 会反复列出已回看过的卡片的问题
