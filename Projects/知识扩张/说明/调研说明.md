# 共享背景（所有调研子任务通用）

## 我们是谁、在做什么
一个中文个人/小团队工作区（git 仓库 /home/user/-001），用 Claude Code 做这些“构建”：
- 新闻事实核查技能 `news-factcheck`（SKILL.md + references + 脚本），把结论存成 Obsidian 事实卡片库（258 张卡），有 factdb.py 做检索/去重/别名/过时替换/到期回看，每周定时任务自动回看
- 把核查结果做成小红书/视频号图文与视频脚本（HTML 模板渲染卡片图）
- 技术调研：Blender/CAD 的 AI 建模工具、Text-to-CadQuery、TeslaMate
- 规划中：Apple Watch 录音 App（手表录音、手机端转文字 WhisperKit/SenseVoice）
- 仓库还没有 CLAUDE.md、没有自动化测试、没有成本统计

## 网络限制（重要，别浪费次数）
- WebSearch 可用（返回摘要）。WebFetch 大多数网站被拦（DNS 不可达）；被拦一次就别再试同一个站
- `git clone --depth 1` 公共 GitHub 仓库可用（github.com 网页本身 403）。克隆放到 <草稿目录>/clones/<短名>/ 下各自新的空目录，只读文件，不要运行里面的任何代码
- PyPI、developer.apple.com 可访问

## 证据要求
- 每条资源必须有来自搜索结果或仓库的 URL，不要凭记忆编 URL。凭记忆知道但没搜到的，confidence 标“低”并在 evidence 写“未核实”
- evidence 写清：一手（官方页面摘要/克隆仓库直读）还是二手（媒体/博客/汇总页摘要，写域名）
- 营销式“十大课程”清单不能当唯一证据
- 标出当前最新一期（edition）和日期；旧版被新版替代的写明
- 特别关注：有没有作业、评分表（rubric）、测验、证书——我们要借用它们的评分标准来定“学到什么程度算会”
