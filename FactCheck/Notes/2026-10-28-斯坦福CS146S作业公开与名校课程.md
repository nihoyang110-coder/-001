## 2. 溯源链
GitHub 仓库（2025-08 建，2025 秋 8 周作业）→ 2026-09 新学期重置仓库、上 GitHub 热榜（aitoolly 等报道）→ 中文跟课博客、手册 → 本视频：用 2025 课程网站截图 + “作业全放 GitHub了”的新闻口吻。
措辞漂移：①“已公开一年”说成新消息；②旧学期课表当成当前课程；③“8 次作业”说成“8 周”（课程 10 周）。

## 3. 先立后破
- **替它说话**：课是真的，作业确实公开，2025 版 8 周作业完整可做，内容描述准确，结语也很克制。
- **攻击点**
  1. 旧闻翻新——**成立**：2026 秋季版前 5 周已换成抓包拆解 Claude Code、MCP+OAuth、写技能、写 CLAUDE.md、智能体就绪度（[[F-0254]]），二手报道称 85% 材料已换。
  2. “公开课”——**部分成立**：作业和阅读清单公开，但没有官方录像，作业批改、讨论区只对选课学生。
  3. 跟着做门槛——**成立**：部分作业依赖斯坦福发放的 Claude Code 账号、bolt.new 积分、Warp 等工具，外部人要自己付费或替换。
  4. 仓库无许可证——**成立**：可以学、可以照着做，不宜原样搬运再发布。

## 4. 对我们有什么用（重点）
2026 版前 5 周几乎就是我们正在做的事的“教科书版”：
| 2026 作业 | 我们对应的东西 | 能直接拿来做什么 |
|---|---|---|
| ③ 写一个技能，评分 15/60/25 | `news-factcheck` 技能 | 按评分表体检：3 句该触发 + 1 句不该触发的测试；正文是否精简、长资料是否放到 references |
| ④ 写 CLAUDE.md / AGENTS.md | 本仓库**还没有** CLAUDE.md | 写一份：库结构、factdb 命令、卡片规则、推送分支、安全规则，新会话不用再靠长摘要 |
| ① 抓包拆解 Claude Code 请求 | “本次花费多少？”的疑问 | 看清每次请求带了多少上下文，找省钱点 |
| ② MCP 服务器 + OAuth | 关注的 Blender MCP、Higgsfield MCP | 评分标准“模型能否选对工具、出错能否恢复”可直接用来评估别人的 MCP |
| ⑤ 智能体就绪度报告 | 本仓库 | 给自己的仓库打分，补测试和文档 |
| 2025 版第 6 周 Semgrep 修漏洞、提示注入 | Blender 自研工具“安全执行层”、处理下载代码的规则 | 阅读材料（Copilot 提示注入 RCE、OWASP Top 10）直接用 |

学习计划见 `Projects/学习计划/名校课程学习计划.md`。

## 5. 白话版
这就像一所名校把“驾校练习题”贴到了网上：题是真的，也确实能拿来练；但视频拿的是去年的那套题，今年学校已经换了一大半新题——新题正好就是教人“怎么写 AI 操作手册、怎么给项目写说明书”，跟我们平时做的事一模一样。没有教练（没有录像、没人批改），得自己对着评分表练。
