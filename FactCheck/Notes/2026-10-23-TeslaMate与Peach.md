# TeslaMate 与 Peach

## ① Peach 蜜桃
截图显示为成人影片资源检索工具（[[F-0239]]）。不访问、不研究、不用于发布；标 `value: 无用`。风险：违法内容、盗版、恶意软件。

## ② TeslaMate
| 说法 | 结论 | 卡片 |
|---|---|---|
| 特斯拉专用自托管数据记录器，Elixir、Postgres、Grafana、MQTT | 属实，AGPL-3.0+，持续更新 | [[F-0240]] |
| 安全警告：仅使用官方版本 | 属实，有假冒网站/App | [[F-0242]] |
| 每个特斯拉车主都能用得上 | 部分属实：要自己部署、24 小时开机设备、处理接口变更 | [[F-0243]] |
| （补充）中国区 | 支持 tesla.cn 接口；旧接口在关闭，Fleet API 要开发者账号和按量付费 | [[F-0241]] |
| （补充）安全事故 | 2022 年配置错误被远程控制 25+ 辆车；后续扫描 1300+ 实例暴露 | [[F-0242]] |

**白话**：TeslaMate 像给特斯拉装了个“私人行车记录仪 + 体检报告”，数据都存在你自己家的机器上。好用、靠谱，但得自己搭；最要命的是别把它直接挂到网上，否则陌生人也能看到你的车在哪。
