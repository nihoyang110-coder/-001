## 2. 先立后破
**最强版本**：一个人做多平台矩阵，最耗时的是“同一内容发 10 个平台”和“回评论”，AiToEarn 把发布、排期、批量生成放进一个开源工具，还能接到推广单，确实降低了一人公司的门槛。

| 攻击点 | 判断 |
|---|---|
| “开源”≠“独立”：要官方 API Key，自部署也推荐借官方平台凭据 | 成立 [[F-0234]] |
| 用网页登录态发布，非官方接口，平台改版即失效、可能触发风控 | 成立 [[F-0234]] |
| 自动点赞/关注/回评属于“模拟真人批量互动” | 成立（平台官方条文未找到）[[F-0235]] |
| 推广市场绕开蒲公英/星图报备、按互动量结算易诱发刷量 | 部分成立（来源二手）[[F-0236]] |
| 项目是否真实、是否开源 | 不成立：仓库与 MIT 许可可证 |

## 3. 对我们的用处
- **可以用**：多平台排期发布（尤其海外平台走官方授权的部分）、批量出初稿
- **不要用**：Engage 自动互动；平台外接推广单（小红书/视频号我们的定位是“有出处的专业分析”，风控和信誉成本高）
- **要注意**：国内平台账号登录信息存在本机客户端；AI 生成内容要按规定标识（[[F-0116]]）

## 4. 白话版
它像一个“自媒体全能管家”：帮你写稿、做图做视频、一键发到十几个平台、自动回评论，还能帮你接广告单。管家本身是开源的，但它开门用的“万能钥匙”默认放在开发方那里；“自动点赞关注”这类活儿，平台很可能当成机器刷量；接的广告单如果不走平台官方报备，也可能被处罚。拿它当“排期发布助手”很合适，当“全自动赚钱机器”有风险。
