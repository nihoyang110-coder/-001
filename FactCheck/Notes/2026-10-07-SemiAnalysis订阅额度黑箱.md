## 3. 先立后破
### 最强版本
第三方用统一方法实测订阅额度，发现：厂商能在不告知的情况下让同价用户额度不同；不同厂商同价订阅的“含金量”差距可达数倍；高价订阅对重度用户是深度补贴，补贴不可持续——这些对付费用户都是重要信息。

### 红队攻击
| 攻击点 | 判断 |
|---|---|
| A/B 测试厂商未点名，帖子语境容易张冠李戴 | 成立 |
| “价值”偷换成“额度”：两家模型 API 单价不同，换算倍数受定价影响，SemiAnalysis 自己承认指标可能误导 | 成立 |
| “涨价 150%”：$200 档仍在，是限额减半 + 新增 $500 档 | 成立 |
| -369% 是极端用户建模，不是公司整体亏损 | 成立 |
| “OpenAI 没有 5 小时限制”找不到出处 | 成立 |
| 实验本身是否存在、数字是否编造 | 不成立：实验和主要数字都有出处 |

## 4. 一句话结论
**实验是真的，主要数字也来自 SemiAnalysis；但帖子把“未点名厂商的小规模 A/B 测试”说得像普遍现象，把“价值 5 倍”说成“额度 5 倍”，把“新增档位”说成“涨价”，还夹带了一条找不到出处的说法。**

## 5. 白话版
有个研究机构买了各家 AI 的会员，用同一本《战争与和平》去“喂”，看每家会员能吃下多少字，再按各家零售价折成钱。结果：同价位里 Claude 折出来的“零售价值”大约是 OpenAI 的 5 倍——但这是按零售价折算，不等于你真能多用 5 倍；而且他们发现某一家（没说是谁）给同价会员悄悄发了不一样的额度，那家说是在做小范围测试。至于“厂商在补贴”，指的是如果你把会员额度用到一滴不剩，厂商在你身上是亏的；大多数人用不完。
