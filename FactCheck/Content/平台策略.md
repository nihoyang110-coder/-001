# 平台策略：小红书 × 视频号

> 证据分级：**[规]** 官方规定/多家主流媒体报道（可信）；**[经]** 运营博客的经验数据（平台不公开算法，只作参考，数字别当真）；**[论]** 传播学经典理论。

## 一页结论
1. **定位**：「有出处的新闻拆解」——别人只给情绪，我们给“数字 + 出处 + 跟你有什么关系”。这是差异化，也正好是合规要求 [[F-0117]]。
2. **标题要抓人，但只用真数字**：反差数字、悬念问句、身边关联三种公式（见第4节）。抓人靠选角度，不靠改事实。
3. **小红书 = 被搜到 + 被收藏**；**视频号 = 被转发**（给家人群、朋友圈）。同一份素材，两套包装。
4. **紧跟热点**：每天从热榜里挑“我们事实清单里已有卡片”的题，快速模式 3–6 小时出稿；预测卡到期日就是现成的续集选题。
5. **红线**：不编、不改数字、不荐股、不唱衰中国经济、不挑动对立、标注来源和标签（第5节）。

## 1. 两个平台的差别

| | 小红书 | 视频号 |
|---|---|---|
| 主要用户 | 年轻、高线城市、女性多 [经，各报告数字不一：女性占比70%–87%] | 30–55岁约六成 [经]；中老年占比高 |
| 怎么被看到 | 推荐流 + **搜索**（月搜索渗透约70% [经]）；搜索流量可持续数月 | **好友点赞/转发**触发社交推荐 + 算法推荐；朋友赞过的会推给他的好友 [经] |
| 核心指标 | 收藏、评论（权重高于点赞）、有效阅读时长 [经] | 完播率、点赞率、转发量 [经，门槛如“完播>45%”仅供参考] |
| 内容形态 | 图文和视频都可；视频曝光权重更高 [经] | 竖屏短视频为主，可挂公众号长文 |
| 用户动机 [论：使用与满足] | 学知识、找攻略、做功课 → **“有用，存起来”** | 获取谈资、转给家人朋友 → **“有面子，转出去”** |
| 合规重点 | 金融生态公约八类禁区 [规 F-0118] | 必选标签 [规 F-0116]；时政须标来源 [规 F-0117] |

## 2. 传播学依据 → 落到操作

| 理论 [论] | 讲的是什么 | 我们怎么用 |
|---|---|---|
| 议程设置 | 媒体决定大家“想什么” | 跟热榜走：大家已经在关注的事，我们给更好的答案 |
| 框架理论 | 同一事实，用不同框架讲效果完全不同 | 用“生活框架”（一份便当）进入，“财政框架”收尾；框架选择是编辑判断，**事实不变** |
| 具体化/可识别效应 | 一个具体的东西比宏大数字更打动人 | 封面永远是一个具体物件 + 一个数字（9%），不是“4.4万亿” |
| 认知负荷 | 一次能处理的信息有限 | 一张卡一件事，每张卡数字不超过3个 |
| 叙事传输 | 有故事线的信息更易被接受和记住 | 固定故事线：小切口 → 谁得利 → 谁吃亏 → 放大 → 卡在哪 → 金句 |
| 信源可信度 | 来源可信，说服力更强 | 每张卡底部写来源；这也是合规要求 |
| 两级传播 | 信息经“意见领袖”二次扩散 | 视频号里每个转发者都是小意见领袖：给他一句能直接转的结论 |
| 敌意媒体效应 | 立场明显的内容会被对立方视为偏见 | 立场越重越难“出圈”；事实型内容才能被不同立场的人都转发 |

## 3. 同类内容的优缺点（类型分析，定性）

| 类型 | 代表 | 优点 | 缺点 | 我们借什么、避什么 |
|---|---|---|---|---|
| 财经科普长视频 | 小Lin说（B站百大，全网千万粉 [经]） | 比喻好、体系完整、可信 | 长、制作慢，跟不上热点 | 借比喻；用短格式抢时效 |
| 机构财经媒体 | 华尔街见闻、财新等 | 快、权威 | 门槛高，不讲“跟你有什么关系” | 借数据；补“对你的影响” |
| 国际新闻搬运/情绪号 | 大量“XX国完了”类账号 | 标题刺激、传播快 | 不标来源、夸大，易被限流封号；同质化严重，读者疲劳 | **完全避开**：这是我们的差异化空间 |
| 知识卡片博主 | 小红书模板化知识卡 | 收藏率高 | 同质化，缺原创分析 | 借卡片形式；加独家核查和事实对照 |

## 4. 标题公式（抓人 + 真实）

| 公式 | 例子（J3） | 用在哪 |
|---|---|---|
| 反差数字 | 日本减税1%：家庭省6万，国家少收5万亿 | 两个平台 |
| 身边场景 + 数字 | 日本明年起，同一份便当店里吃贵9% | 小红书封面 |
| 悬念问句 | 日本消费税降到1%，为什么餐馆反而难了？ | 小红书标题 |
| 代价/压力 | 一份便当，暴露日本每年5万亿的财政窟窿 | 视频号 |
| 关联读者 | 去日本旅游的注意：明年超市便宜了，餐馆没变 | 视频号描述/置顶 |

**写法规则**
- 小红书标题 ≤20 字，前半句放搜索词（“日本消费税”“日本减税”“日元”）[经]；封面字 ≤15 字 [经]
- 数字必须在事实对照表里能找到
- 问句、感叹可以用；“崩盘/完蛋/暴雷/彻底”这类词不用

### 关于“让读者看到日本压力很大”
可以做，前提是**选真实的压力事实来讲**，而不是夸大：
- ✅ 能讲（都有卡片）：每年少收4.4–5万亿日元、财源没着落、机构预测国债利率升到3%、参院差4席、日元承压、霍尔木兹危机逼日本恢复进口俄油
- ❌ 不讲：“日本经济崩溃”“日本人吃不起饭”这类没有证据的说法
- 为什么：①会撞上“歪曲事实/恶意挑动情绪”的整治 [规]；②“日本完了”类内容中文圈已经很多，没有差异化；③一旦被扒出夸大，账号的“有出处”定位就没了，这是我们唯一的护城河。
- 实操：标题用“压力/代价/窟窿/难题”框架，正文给出处，结尾留一句“日本情况复杂，下一步看12月”——既抓人，又经得起查。

## 5. 限流与违规清单

| 风险 | 小红书 | 视频号 | 我们的做法 |
|---|---|---|---|
| 标题党（文不对题、惊悚夸张） | 限流 [经] | 违规，严重可封号 [经] | 标题里的数字正文必须有 |
| 编造/歪曲时事 | 违规 | 违规；网信办“清朗”整治谣言 [规] | 只用有卡片的事实 |
| 未标信息来源（时事/政策） | — | 要求显著标注 [规 F-0117] | 每张卡来源行 + 视频结尾来源页 |
| 未选必选标签 | — | 无法发布 [规 F-0116] | 选“内容为个人观点”；AI生成画面/配音选AI标签 |
| 金融荐股、保本承诺、唱衰经济 | 八类禁区 [规 F-0118] | 违规 [经] | 不给投资建议，结尾注明 |
| 挑动对立/地域攻击/谩骂 | 违规 [经] | 违规 [经] | 不贬低任何国家的人，只讲政策和数据 |
| 诱导互动（“点赞收藏再看”） | 低质信号 [经] | — | 用真实问题引导评论，不求赞 |
| 站外导流（二维码、微信号、链接） | 限流 [经] | — | 不留联系方式 |
| AI批量低质内容 | — | “清朗·AI”整治 [规 F-0119] | 每篇人工核查，事实对照表留底 |
| 敏感政治元素（领导人画像、国旗变形等） | 违规 [经] | 违规 [经] | 卡片不用政治人物照片和国旗 |
| 极限词（最、第一、唯一） | 违规词 [经] | 违规词 [经] | 用具体数字代替 |

## 6. 热点工作流
1. 早上看热榜：微博热搜、百度热搜、小红书热点、今日头条（需要网络放开后我才能直接读）
2. 选题标准：热度高 × 有国际/经济维度 × **事实清单里已有卡片或能快速核查**
3. 快速模式核查（3–5 次搜索）→ 选“小切口” → 出 8 张卡 + 80 秒脚本
4. 发布时间 [经]：工作日 12:00–13:30、18:30–22:30；周末 10:00–12:00、15:00–23:00
5. 续集：预测卡到期（`factdb.py due`）= 跟进选题。例：12-12 临时国会结束 → “日本减税到底过没过？”
