# 多平台运营：我们现在怎么做 vs AiToEarn，能借鉴什么

> 背景：[[2026-10-21-AiToEarn一人自媒体全流程]]。目标平台：小红书、视频号、YouTube。

## 1. 流程对照
| 环节 | 我们现在 | AiToEarn | 差距 / 借鉴 |
|---|---|---|---|
| 选题 | 用户转来截图 → 核查；`关注清单` + 每周回看 | 品牌监测、热点追踪 | 缺“主动找题”：可加每周热点扫描 |
| 研究 | **事实核查 + 事实卡 + 扩展分析**（我们的核心） | 无 | 这是我们的护城河，保留 |
| 创作 | J 模板 8 张图卡 + 视频封面 + 文案 + 视频脚本（只有脚本，没有成片） | 调视频/图片模型批量出成片 | 借鉴：脚本 → 自动合成成片 |
| 多平台改写 | 只有小红书、视频号两版 | 一份素材分发 14 平台 | 借鉴：一稿多版（加 YouTube 英文/长视频/Shorts） |
| 合规 | 事实对照表、限流红线、AI 标识、来源说明 | 基本没有 | 保留并扩到 YouTube 规则 |
| 发布 | 手动发 | 一键分发 + 日历排期 | 借鉴：发布日历；分发可手动或用其“排期发布” |
| 互动 | 置顶评论；无系统处理 | 自动点赞/关注/AI 回评、评论挖掘 | 只借鉴“评论挖掘”（找提问和质疑做新选题），不做自动互动 |
| 复盘 | 计划写 `复盘.md`，未落地 | 不明 | 补上：每篇数据回填 + 每月总结 |
| 变现 | 未规划 | 推广任务市场 | 暂不跟；以后走蒲公英/视频号互选/YouTube 合作计划等官方渠道 |

## 2. 三个平台的区别
| | 小红书 | 视频号 | YouTube |
|---|---|---|---|
| 主形态 | 3:4 图文卡片 | 9:16 竖屏短视频 | 16:9 横屏长视频 + 9:16 Shorts（≤3 分钟） |
| 语言 | 中文 | 中文 | 英文为主（或中文面向海外华人） |
| 发现机制 | 搜索 + 推荐 | 社交关系 + 推荐 | 搜索 + 推荐，标题/缩略图/章节决定点击 |
| 变现 | 蒲公英商单 | 互选平台、带货 | YPP 广告分成、会员、赞助 |
| AI 规则 | 网信办 AI 标识（[[F-0116]]） | 同左 | 真实感 AI 内容需上传时披露；**批量重复的 AI 配音幻灯片不能变现**（[[F-0238]]） |
| 我们的现状 | 有模板 | 有封面 + 脚本 | 有模板（2026-10-21）：`YouTube模板.md` + 16:9 缩略图；合规见 [[平台策略]] 第 5.1 节 |

## 3. 借鉴清单（按优先级）
1. ✅（2026-10-21 已加模板和合规清单，成片合成未做）**一稿多版**：同一篇核查自动产出：小红书图卡、视频号脚本 + 字幕、YouTube 英文脚本（长视频 6–10 分钟 + Shorts 1 分钟）、英文标题/描述/章节/16:9 缩略图
2. **成片合成**：图卡 + 配音 + 字幕 → MP4（9:16 和 16:9），先用免费工具（ffmpeg）合成；YouTube 版须真人出镜或真人配音，避免“AI 配音幻灯片”被判不真实内容
3. **发布日历**：`Content/发布日历.md`（Obsidian 表格）：每条内容的平台、计划时间、状态（草稿/待审/已发）、链接
4. **评论挖掘**：用户把评论导出或截图发来，自动分类：追问 → 新选题；质疑 → 回看事实卡；夸奖 → 不处理。只出“建议回复”，由人发
5. **复盘回填**：每篇发布 48 小时、7 天各填一次数据；每月出一份“哪类选题/标题好”的总结
6. **热点扫描**：并入每周回看任务，列 5 个可核查的热点候选

不借鉴：自动点赞/关注/回评、平台外接推广单、用网页登录态自动发国内平台。
