# 我们的事实清单

> 规则：每个可验证的命题一张卡片，放在 `Facts/`，编号 F-xxxx，永不删除。
> 新闻笔记只引用卡片（`[[F-0005]]`），不重复写结论。同一命题再次出现时，补充细节就更新原卡；**新事实推翻旧事实**时新建卡片，并用 `factdb.py supersede` 把旧卡标为“已过时”。
> `as_of` 是事实成立的时间，`last_checked` 是我们核实的时间。常见公司见 `Entities/`，同义词见 `别名表.md`。

## 状态说明
| status | 含义 | 能不能拿去引用 |
|---|---|---|
| 已证实 | 两个以上独立可靠来源一致 | 可以 |
| 公司自述 | 只有当事方自己说，无第三方核实 | 引用时必须写“据公司称” |
| 部分属实 | 核心对、细节或口径有问题 | 带注释引用 |
| 存疑 | 找不到原始来源或互相矛盾 | 不引用 |
| 证伪 | 有证据证明是错的 | 拿来当反例 |
| 观点 | 不是事实，是某人的判断 | 写清楚“谁认为” |
| 待验证 | 预测，尚未到期 | 写明到期日 |
| 已过时 | 曾经成立，已被新卡取代 | 不再引用，改引新卡 |
