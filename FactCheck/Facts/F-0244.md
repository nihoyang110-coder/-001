# 特斯拉官方的第三方接入途径：Fleet API + 虚拟钥匙 + 开源工具

- 车主自购车辆不允许特斯拉远程添加第三方钥匙，必须车主在车内确认
- 频率限制据第三方指南：实时数据 60 次/分钟、唤醒 3 次/分钟、命令 30 次/分钟（未核实官方原文）
- 官方开源灯光秀仓库 teslamotors/light-show、U 盘自定义锁车音等为既有知识，本次未核实中国区可用性
