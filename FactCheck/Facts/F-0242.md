# TeslaMate 的主要风险在于部署不当：2022 年安全研究员 David Colombo 借助配置错误、公开在网上的 TeslaMate 面板远程控制了 25 辆以上特斯拉（开门、鸣笛、启动等，相关缺陷已修复）；之后的扫描又发现 1300–1400 多个无需登录即可访问的实例，暴露实时位置；官方 README 另警告有假冒网站和 App 分发恶意改版

- 做法：只在家里网络或通过 VPN 访问，绝不直接暴露到公网；改掉默认密码；只从官方仓库安装
