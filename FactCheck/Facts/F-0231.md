# 社区项目 MCP for Blender（原名 blender-mcp，作者 Siddharth Ahuja，MIT）：约 2.9 万星（2026-09-20），让 Claude、Codex、Cursor 等通过 MCP 读取场景、执行 Python、搜索导入 Poly Haven/Sketchfab 素材、调用 3D 生成服务；2026 年披露两个漏洞：execute_blender_code 不做沙箱即执行代码（CVE-2026-10688）、Poly Haven 下载路径穿越可写任意文件（CVE-2026-66004，1.6.5 修复）

- 安全建议：只在本机监听、重要文件先备份、能用专用工具就不用“执行任意代码”
