# CS146S 2026 秋季版前 5 周作业：①用 mitmproxy 抓包拆解一次真实 Claude Code 会话的请求；②给第三方 API 写 MCP 服务器，评分看“模型能否选对工具、调对参数、出错后恢复”，并要求 OAuth；③写一个技能（Skill），评分 流程 15/技能 60/测试 25，要求 3 个应触发和 1 个“不该触发”的测试；④给陌生开源仓库写 AGENTS.md 或 CLAUDE.md；⑤用 Factory 的 Droid 给 3 个开源仓库跑“智能体就绪度”报告并比较

- 第 1 周要求用斯坦福提供的 Claude Code 账号
- 第 3 周评分强调：描述要能触发、正文写判断而不只是步骤、确定性部分给精确命令、正文精简、长资料放支持文件
