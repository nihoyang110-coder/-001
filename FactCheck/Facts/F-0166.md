# “功能单一的小工具 App 护城河一夜清零”

- 反方 1：AI 现场拼的计算器可能“看起来专业、算得不对”，Omni Calculator 专门测过这类“以假乱真的幻觉”；有预印本称生成式界面中超过 25% 的设计说明没有被真正实现
- 反方 2：OpenAI 自认“设计判断仍需改进”
- 反方 3：OpenAI 同时用 Apps SDK 把第三方应用请进 ChatGPT，对工具类 App 既是替代也是新渠道
- 合理部分：一次性、低频、无需数据积累的小计算（分账、换算）确实最容易被聊天框顺手完成
- 可检验的部分拆成预测卡 [[F-0167]]
