# SemiAnalysis 于 2026-10-05 发布《Anthropic Subscriptions Offer 5x+ More Value Than OpenAI》，实测 Anthropic、OpenAI、Meta、SpaceXAI、MiniMax、Moonshot、Zdotai、Cursor、Cognition 等订阅方案；方法是把《战争与和平》文本分块喂给付费账号，记录 5 小时与每周窗口的用量百分比，再按公开 API 价换算成“API 等价价值”

- 测试起因：OpenAI 9-29 下调 $200 档限额后重新测量
