# OpenAI 于 2026-10-07 发布《GPT-6 and Intelligent UI for everyone》：ChatGPT 的普通聊天（Chat）里上线 GPT-6，回答可按问题自动组合文字、图表、按钮、表单、地图以及计算器、分账器、小游戏等临时小工具；OpenAI 自己承认模型的“设计判断仍需改进”

- 视频说“改个数字全表实时联动”：报道提到可编辑图表、任务计算器，方向一致，但未见“全表联动”的原话
- 视频说“用完即弃”：未见 OpenAI 原话（Claude 的同类功能官方说明是“临时的”）
- 视频里的“7 速自行车爆炸图”演示未找到出处
