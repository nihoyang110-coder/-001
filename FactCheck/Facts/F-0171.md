# 截图里被称为“模型路由”的演示，画面实际显示的是主 Bot（SuperGrok）给另一个 Bot（indigo-mind）发消息、再把对方回复转给用户——这是 Grok Bot 官方的多 Bot 协作功能；画面本身无法证明调用了其他厂商的模型（唯一线索是会话名“Gemini 润色版”）；有资料称用户不能在 Grok Bot 里手动选底层模型

- “Bot 之间转发”≠“在模型之间路由”：前者是分工，后者是按任务挑模型
- 可能的实现：某个 Bot 在自己的云电脑上用 API 密钥调用 Gemini 等模型，但截图看不出来，需看完整直播
- 作者自己也标注“个人观点，仅供参考”
