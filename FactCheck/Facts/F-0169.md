# 马斯克 2026-10-06/07 在 X 发帖：今后 SpaceX 会为 Grok Bot 的每个任务选择最合适的后端模型，包括 Claude Opus 5.5、Midjourney、Suno 等主流 API；未公布哪些任务走哪个模型，官方文档也尚未写明

- 视频“Elon 说 Grok Bot 要支持多模型”属实
- 但这是“由 SpaceX 在后台替你选模型”，不是“用户可以自己挑模型”
- 有报道称一名 Grok Bot 员工发帖说所有 Bot 将由 Opus 5.5 驱动，可再派生运行 Cursor 模型的子智能体；官方未确认
