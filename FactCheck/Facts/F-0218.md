# “8 个技能包让 Codex 自动干活”：GitHub、Figma、Sentry、Vercel、Linear 有官方 Codex 插件；Supabase 有插件但是否在官方名单说法不一；Context7（文档查询）和 Playwright（浏览器操作）主要以 MCP 服务器形式接入，Playwright 也在 OpenAI 精选技能里；各项功能描述大体正确

- “技能包”是统称：实际分插件、技能、MCP 服务器三类，安装方式不同
- “自动部署”“自动修 bug”仍需你授权账号、在审批模式下确认，不是装上就全自动
- 视频标注“含 AI 生成内容”，账号为孵化基地，带推广性质
