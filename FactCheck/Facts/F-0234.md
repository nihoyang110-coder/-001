# AiToEarn 的“开源”依赖官方云服务：接入 MCP、OpenClaw、Docker 自部署都要先到 aitoearn 官网注册拿 API Key；自部署文档“强烈推荐”配置 Relay，借用官方在各平台的开发者凭据完成授权，否则要自己去十几个平台逐一申请；国内平台（抖音、小红书、视频号等）由桌面客户端用你登录后的 Cookie 调用网页接口来发布

- 白话：代码能自己装，但“钥匙”默认还是放在他们那里；账号登录信息存在你本机客户端
- 用网页登录态而非官方开放接口发布，平台改版就可能失效，也存在账号风控风险
