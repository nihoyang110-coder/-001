# Text-to-CadQuery（arXiv 2505.06507，投稿 IEEE T-ASE）的 GitHub 仓库公开了数据标注脚本（用 Gemini 2.0 Flash 给 Text2CAD 数据集补 CadQuery 代码）、6 个模型（CodeGPT-small 1.24 亿参数、GPT-2 中/大、Gemma3-1B、Qwen2.5-3B、Mistral-7B）的训练和推理评测脚本；权重和数据放在 Hugging Face 账号 ricemonster；仓库 2025-05 创建、2026-08 最后更新，**没有 LICENSE 文件**

- 没有许可证 = 默认保留所有权利，严格说不能算“开源可随意使用”
- 基座模型许可各不相同：Qwen2.5-3B 基座为 Qwen 研究许可（限制商用），第三方页面把其微调版标成 Apache-2.0，未在 HF 原页核实
- 本环境网络屏蔽 Hugging Face，未能下载权重实跑
