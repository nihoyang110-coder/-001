# TeslaMate 支持中国区特斯拉账号（文档给出 tesla.cn 的接口地址）；但特斯拉在逐步关闭旧的车主接口（Owner API），改用 Fleet API：需要注册特斯拉开发者账号、准备自己的域名，且自 2025-02 起按调用量收费

- 旧接口对个人用户是否仍可用，各方说法不一，以 TeslaMate 文档为准
- 中国区 Fleet API 的实际开通与费用情况本次未核实
